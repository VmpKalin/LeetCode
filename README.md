# LeetCode Solutions

A collection of [LeetCode](https://leetcode.com/) problem solutions written in C# (.NET 9).

## Project Structure

Each problem lives in its own file inside the `LeetCode/` project. `Program.cs` serves as the entry point for running and testing solutions locally. Shared helper types (e.g. `TreeNode`) are defined in their own files.

- [.NET SDK 9.0](https://dotnet.microsoft.com/download/dotnet/9.0) or later

```bash
dotnet run --project LeetCode
```

Edit `Program.cs` to call the solution you want to test.
